允许 Agent 使用什么

本地管理
能力开关在重启后回到默认状态。远端 Agent 无法修改这些权限或恢复暂停。

Chrome DevTools MCP 等待检测

在 Chrome 144+ 中打开 chrome://inspect/#remote-debugging，开启远程调试。首次调用时，在 Chrome 中允许连接。

macOS 系统权限

在「系统设置 → 隐私与安全性」中授予屏幕录制和辅助功能权限，再重新启动程序。

MCP 连接配置
远端接入时，只转发 Agent 接口端口，并使用 HTTPS 隧道。控制台端口仅供本机使用。
